用户要求“先把 SELC 基础可用版发布出来吧，同步到 GitHub 和 Gitee。自动统计先标为实验功能，后续再完善，不要再跑模型测试了”。本次明确授权基础版提交、非保护分支整合、版本标签、Release/制品上传及两个已有公开仓库的同步。沿用既有账号，不购买额度、不新增模型请求。它取代当前基础版必须等待 T011 真实资格完成的发布范围；不豁免实验功能本身的严格证据校验，也不把 T011 标完成。

自动统计、observed hooks、one-shot、native 归因、真实 creator/评估以及自动贡献/发布流水线全部标为实验功能。保留 T011 的 RECEIPT_UNAVAILABLE 和未验证范围，不声称生产完整性。发布基础框架/普通示例不属于通过实验流水线发布某个已经合格的受管业务候选，不能关闭或伪造该资格校验。

## 验收

- README 和作者/生成维护说明准确区分基础能力与实验能力，不再把完整基础分发称为仅开发预览。
- 发布 tag v0.1.0 固定同一已验证/评审的源代码内容；GitHub 与 Gitee 至少具有一致发布分支和 tag，并提供可访问的版本入口。两个平台的源码和说明同步；制品如受平台限制需明确提供固定同版本下载链接。
- 提供源码、框架 ZIP、普通 skill ZIP、基础套件 ZIP 和 SHA256SUMS；全新解包中进行必要 doctor/basic install/实际合成脚本 smoke，校验下载后的资产哈希。
- 本轮无模型测试；复用适用的既有离线回归，独立验证只执行本次源码分发及新解包制品所需检查，不重复无变化的全量回归。
- F-002/T011 保留未完成，F-003 只记录本次基础版发布成立，不以拆分任务重置原失败或诊断额度。
