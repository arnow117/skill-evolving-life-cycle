##### NEED-003：按交付产物和用户反馈衡量任务成功

- **状态**：confirmed
- **陈述**：依据交付产物及用户反馈衡量任务成功，首次 one-shot 与当前最终交付结果分开记录。首次交付满足要求、过程中无需人工业务判断或纠错且证据充分时，为 one-shot 成功；内部自动检查和重试不算人工介入。首次失败后经人工纠错得到有效产物，单独统计为补救成功，不恢复首次 one-shot；证据不足的判断保留 unknown。
- **适用边界**：补齐预先声明的必要客观输入、纯工具权限点击不算人工介入，但单独记录；权限点击与等待单列。方案选择或业务口径判断即使发生在开头也计入介入；人工定位、纠错、补做及流程要求的业务审核计入介入。完成交付后的自愿反馈不追溯算执行介入；流程必须等用户审核才能完成则算介入。one-shot 从必要输入就绪后判定，任务从最初请求保留完整记录，不能通过重新登记隐藏介入。详见 DEC-006 及 DEC-007 的后续补充。
- **产物与反馈规则**：验证对象是 SELC 管理的 skill 执行后的业务产物，按执行前确定的要求和对应交付版本保存逐项结果、依据及规则版本。自动验证与用户反馈分别保留，并按 DEC-007 已确认的 pass / fail / unknown、反馈修订和冲突规则处理；不把 skill 自身创建 / 迭代 / 发布验证混入业务产物成功判断。
- **统计口径**：整体任务与调用分开计数；首次 one-shot、最终交付各自独立统计成功 / 未达成 / unknown、成功率下界、已知结果成功率与覆盖率。整体任务按发起方、调用按执行方分组，具体公式及记录要求见 DEC-008。
- **理由**：用户关注任务实际交付效果，而不仅是 skill 被调用或进程正常结束。
- **用户证据**：SRC-001，“通过交付产物及用户反馈来计算，one shot交付产物中间无需人判断算成功”；SRC-006 认可已展示结果定义；SRC-007 认可介入边界；SRC-008 认可业务产物验证与反馈规则；SRC-009 明确“整体任务与调用分开计数，首次 one-shot 和最终交付分别统计，主报成功率下界，同时展示已知结果成功率和覆盖率”。
- **确认时间**：2026-10-17。
- **解释边界**：人工介入类别与判定起点见 DEC-006，业务产物验证与反馈见 DEC-007，统计分母、任务 / 调用计数及双轴报表口径见 DEC-008。评分、宿主观测完整性及具体验证器 / 采集实施细节仍 open，也未因此视为已验证可用。

- **状态**：confirmed

##### DEC-008：整体任务、调用与双轴成功率

- **状态**：confirmed
- **决定**：整体业务任务与 skill 调用使用独立样本和分母；首次 one-shot 与最终交付结果独立判定、独立统计。
- **计数单位**：一个整体业务目标计一个任务样本，多阶段、跨 harness 委托、重试和中断恢复不重复增加整体样本。每次 skill 实际调用使用调用样本及独立分母，不与任务样本相加或混用。
- **双轴判定**：首次 one-shot 和最终交付分别记录“成功 / 未达成 / unknown”。最终已成功不能证明首次 one-shot；首次未知但最终已知时，分别进入首次的未知数和最终的可判结果数，两维不共用结果分类或覆盖率。人工辅助 / 补救作为标签分项展示，不用它推导另一维度的结果。
- **分母与未知**：整体任务报表的 N 是全部已观测启动的业务任务数，只覆盖已观测样本。运行中、取消、中断及证据缺失保留状态和原因；该维度没有结论时为 unknown，不从主分母删除；已有明确结果则按证据归类，不因运行状态一律改成 unknown。调用报表以全部已观测启动的调用数为独立分母。
- **展示与归属**：整体任务按发起方分组，调用按实际执行方分组；展示样本数、统计时点、版本和 harness。迟到反馈依 DEC-007 更新当前统计并保留历史；对应分母为零时显示“暂无样本”，不显示百分比。

对同一整体任务样本集，两维的变量分别为：

| 变量 | 首次 one-shot | 最终交付 |
|---|---|---|
| 可判成功数 | S_one | S_final |
| 可判结果数（成功 + 已知未达成） | K_one | K_final |
| 未知数 | U_one = N - K_one | U_final = N - K_final |
| 主报成功率下界 | S_one / N | S_final / N |
| 已知结果成功率 | S_one / K_one | S_final / K_final |
| 结果覆盖率 | K_one / N | K_final / N |

每一维度独立满足 `0 ≤ S ≤ K ≤ N`、`N = K + U`。调用报表采用同样的独立计算原则，但使用调用样本的分母，不使用整体任务 N。

确认时示例：N=10，其中 6 次首次 one-shot 成功、1 次人工补救成功、1 次失败、2 次双轴均 unknown：

| 维度 | 可判成功数 | 可判结果数 | 未知数 | 下界 | 已知结果成功率 | 覆盖率 |
|---|---|---|---|---|---|---|
| 首次 one-shot | 6 | 8 | 2 | 60% | 75% | 80% |
| 最终交付 | 7 | 8 | 2 | 70% | 87.5% | 80% |

本例两维覆盖率恰好相同，不代表其他样本可共用覆盖率或用首次分类推算最终结果。

##### 边界情况

- **离线 / 无上游权限**：本机已具备的运行与统计能力仍可使用，文件可访问时显式导出 / 导入不要求云端同步；上游检查或发布不可用时单独说明，不冒充已同步。
- **任务中断 / 取消**：区分未结束、已中断、已取消和已交付；首次判定证据不足时保持未知，已有明确首次失败证据不能因任务仍运行而回到未知。未结束和取消原因可单列，但不从全部已观测启动的样本中删除；恢复不额外制造一次整体交付。
- **未知 harness / 能力缺失**：来源或介入观测显示未知，缺失维度不伪装成已知事实；Agent 自报事件不能补足宿主能力或事件连续性缺口。
- **缺失 / 损坏产物**：无交付证据不能自动成功；有明确失败证据则失败，单纯观测丢失则未知。
- **重复反馈 / 迟到反馈**：反馈按 DEC-007 绑定交付版本并保留修订；DEC-017 确认重复导入去重和迟到反馈可修订汇总。具体事件识别、去重与修订 / 冲突协议仍待设计，不要求导出反馈正文。
- **空统计**：依 DEC-008 分别处理两维；N 为零时显示“暂无样本”，N 大于零但该维度 K 为零时仍显示该维度有依据的下界和覆盖率，已知结果成功率显示“暂无样本”。对应分母为零时不显示百分比。
- **嵌套阶段 / 同时运行**：每次业务任务保留身份，不能把不同用户任务合并，也不能把一次复合任务拆成多个整体成功样本。
- **未导出 / 统计删除**：未显式导出 / 导入时仅本机保存；明细不自动过期，按套件和时间范围删除时明确说明统计影响。已导出 / 分享的文件不因本地删除自动撤回；删除后重导入、多份导出文件的处理仍待设计，已确认产品规则见 DEC-017。

###### 体验与质量（按条目标注确认范围）

- **NFR-P-002 数据一致性**：用重复调用、重试、阶段嵌套和恢复案例核对，整体交付不重复计数；同一任务在各入口查询得到相同当前结果。反例见 SCN-008、SCN-017。

- **NFR-P-005 交互可用性**：以文本可读的入口、状态和恢复提示完成关键操作；空、处理中、离线、权限不足、错误均有明确反馈，不只依靠颜色。首版是否需要网页界面未确认，本文不提出视觉界面验收。

- **观察条目**：整体任务按发起方、调用按执行方及各自版本 / harness 分组，使用独立分母。首次 one-shot 和最终交付分别展示 N、S、K、U、统计时点，以及各自的成功率下界 / 已知结果成功率 / 覆盖率，口径见 DEC-008；依 DEC-011 将测试调用与真实业务统计分开，候选按固定评估比较业务产物 / 人工介入 / 成本，不用不同时期真实均值替代该比较。
