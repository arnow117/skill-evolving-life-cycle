- **职责**：在 `stats_report.py` 打开受支持 SQLite 的一致读取事务，复用 records 去重与聚合，将敏感样本字段仅保留在进程内的必要计算范围，输出分区四轴计数。

##### 独立 HTML 模板与浏览器筛选

- **职责**：在独立 `src/selc/stats_report_template.py` 保持可读的 HTML/CSS/JS。呈现项目并列、单项目四轴、维度筛选、分组、状态与快照提示；无服务、fetch、CDN、远程字体、storage 或模型。

- **覆盖**：REQ-401–403、REQ-405–406。

##### 安全输出器

- **职责**：验证唯一显式输出目标，在同目录临时文件完成严格编码、写入和 fsync 后原子替换；前置或写入失败保留旧有效文件并清理本次临时文件。
- **接口**：报告生成入口内部能力，不新增通用文件管理 API。只写输出和其临时文件，不创建输出父目录或源目录。
- **覆盖**：REQ-404–405。

#### 关键设计决定

##### 决定 1：只读兼容范围显式收窄

- **背景**：当前数据库 writer protocol 为 6，连接默认 rollback/DELETE journal；只读报告不承担旧库迁移、hot journal 恢复或任意 SQLite 模式兼容。
- **决定**：连接前读取 SQLite header 并拒绝 WAL 标记、`-wal`/`-shm` 来源；不使用 `immutable` 忽略活跃 WAL。使用 SQLite URI `mode=ro`、`PRAGMA query_only=ON` 和显式 `BEGIN`，在首次 schema/数据读取建立的同一事务内核对格式并完成两个样本集合及分区投影。设置短 busy timeout 与有截止时间的 progress handler，关闭/回滚只读事务后再渲染。
- **兼容范围**：只接受已知 writer protocol 6 与 records 读取必需的真实表/列；当前 `SCHEMA_VERSION=1` 是应用合约，不向源库补写版本字段。缺失、非法或未来 protocol/列清楚报不支持；字段存在但旧 nullable provenance 按现有 normalize 规则保留 unknown，不承诺任意旧 schema。状态检查使用只读查询，不执行 `PRAGMA journal_mode=...`。
- **取舍**：支持当前 writer 在 rollback journal 下的正常并发写入和一致读取；WAL、热恢复、外部 journal-mode/路径替换不属于受支持并发。若来源状态改变或无法建立可靠快照，返回该源错误，不降级为忽略 journal 的读取。Build 必须以源文件/目录前后证据检查正常、拒绝和忙路径的零源写入；无法满足时先报告，不能弱化此要求。
- **覆盖**：REQ-404–405；SCN-409–411、SC-402。

##### 决定 2：去重后分区，只嵌入计数

- **背景**：库内去重需要 subject identity/provenance；HTML 不需要这些字段，且必须支持离线切换测试和维度。
- **决定**：事务内分别按 `include_test=False` 与 `True` 调用 `_deduplicated_samples`，为两种范围各形成一份最少计数投影；不能先将测试/非测试混合去重后再按代表行的 is_test 过滤，因为现行 records.stats 在去重前排测试。两份投影在同一只读事务内，为任务按 suite/version/harness/initiator/is_test、调用另加 skill/executor 分区；用 `_metrics`/`_group_metrics` 的既有双轴语义形成 N/S/K/U，投影时丢弃比例与所有不在允许表中的字段。浏览器测试开关先选对应投影，再按维度筛选，不叠加两个范围；`--include-test` 只改变初始开关。文件明确说明包含可切换的最少测试汇总。
- **取舍**：HTML 不含 subject ID、evidence、prompt、反馈正文、原生日志、凭据、原始绝对来源路径或业务产物。只能在同项目分区内合计；不引入跨库去重/全局成功率。JS 必须与 Python 参考值进行确定性对照。
- **覆盖**：REQ-401–403、REQ-404；SCN-401–408。

##### 决定 3：原子输出与离线内容隔离

- **背景**：输出也是持久化边界，路径别名或生成失败不能破坏源文件和旧报告；分组名称为不可信数据。
- **决定**：输出必须为 `.html`，父目录已存在；保留原始 Path 信息进行 lstat，不能先 resolve 后丢失 symlink 事实。拒绝 symlink、非普通文件及多硬链接/源文件 inode 别名；canonical 目标不得位于任何来源 `.selc` 内，也不得覆盖 reader 使用的受保护源文件。替换前重新核对目标和父目录身份，防止已识别路径变化继续覆盖。
- **写入语义**：完整渲染并严格 UTF-8 编码，孤立 surrogate 等失败在提交输出前返回错误。同目录独占临时文件 → 完整写入/flush/fsync → 原子 replace；replace 为发布新文件的提交点，之前失败旧文件不变。提交后若目录 fsync 失败，完整新文件已经可见，必须返回已生成及明确的持久化警告，不能返回“整体失败/已保留旧报告”，也不执行覆盖式回滚。目标在复核时消失同样属于变化，拒绝继续。正常失败清理本次临时文件；崩溃不承诺主动清理，但目标只会是完整旧版或完整新版。不新增源库锁文件或目录。
- **页面隔离**：meta CSP 以当前嵌入 script/style 的 hash 明确允许本文件代码，其余资源采用拒绝策略；JSON 安全编码防止 `</script>`/分隔符突破，动态文本只用 `textContent` 或同等安全 DOM，不拼接业务字符串为 HTML。输入中的长文本或特殊字符不执行代码。
- **覆盖**：REQ-404–406；SCN-409、412、413B、SC-402/404。

#### API / 接口契约 *(Feature 暴露 API 或 CLI 表面时包含)*

- **拟实现接口**：`stats-report --project-root <p> [--project-root <p2> ...] --output <x.html> [--include-test]`。至少一个显式来源；输出必需。参数以 `cli.py` parser 为权威，当前签名是待实现合约，尚无实际运行命令证据。保留 `stats --project-root ...` 的既有 JSON 输出/参数。
- **返回行为**：成功生成返回既有 CLI 风格的结构化摘要，包含输出位置、逐源状态及是否 partial，不带样本正文或敏感字段。至少一个有效库或可核实 basic 无采集状态时可生成；单个坏源在报告内清楚报错。全源均不可用时整体失败，不覆盖旧报告。有效空库才产生 N=0/null；可核实 basic 且缺 DB 为正常不采集状态，不伪造零样本统计；缺 DB 且模式不明为未知错误。
- **模式核实**：仅只读解析存在的 `.selc/installations.json`，按已有登记模式语义解释；损坏、混合/不完整或缺登记时保留无法核实，不调用安装查询中可能写库/修复的路径。不因 observed 标记宣称健康或完整。
- **错误**：来源不存在/目录错误、无权限、非法/不支持库、WAL 来源、忙/超时、非法输出/别名、编码/写入失败有稳定分类和恢复提示；报告错误不得包含不必要的原始路径、SQL 行值或异常正文。CLI 可返回显式输出路径，但 HTML 不嵌入原始绝对来源路径。
- **异常隔离与诊断**：registry/数据库元数据访问也属于逐源读取，权限错误不能逃逸并使正常项目失败；输出前置检查不能因读取无关坏源身份失败而取消安全的 partial 输出。全源错误仍返回整体失败，但既有 CLI 错误消息/恢复提示须保留每个脱敏来源名、分类及相应恢复动作，不丢失已收集诊断。无须扩展通用 SelcError 协议。JSON 中的 `<` 等 HTML 特殊字符统一转 Unicode escape，不能仅替换关闭 script 标签。
- **输出回读**：HTML 仅从其内嵌数据筛选；浏览器刷新仍是旧快照。获取新统计需再次执行生成接口。整体失败按决定 3 保护旧文件。

#### 横切质量设计 *(性能 / 安全 / 可用性影响设计时包含)*

- 只读事务使用最小生存期，数据读取后即释放；busy/progress 限制必须为有限值并在 Build 记录。报告实际项目数、样本规模、读取耗时，不虚构实时性指标。
- 页面遵守 REQ-004/DEC-404 的 Operate/platform 普通布局：语义表格、清晰标题/分母/快照说明、系统字体、键盘焦点、无颜色单一含义、375/768/1440px 可操作与局部表格滚动、AA 对比与 reduced motion。无新增品牌概念或设计系统文件。
