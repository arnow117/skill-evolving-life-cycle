# Maintaining this suite

Keep the installed suite immutable. For an uninstalled authoring source, run the available skill-creator validation after editing a declared skill or resource, then explicitly run `$SELC_PYTHON bin/selc-suite.py seal --suite <authoring-source>` before `validate` and `package`. Seal only refreshes that source manifest after checking its existing runtime; it does not adopt installed local edits or update an installation registry. Set `SELC_PYTHON` to a Python 3.11+ interpreter, then prepare an isolated candidate with `$SELC_PYTHON bin/selc-suite.py evolve prepare --suite . --output <candidate-parent>`, then edit only the resulting candidate `skills/` and declared `resources/` files. `evolve evaluate` is a fixture diagnostic only. Before a supported Codex plan, generate a complete private alpha.11 `evolve policy-template` with its narrow Python readonly root and copy it into the matrix; raw policy-digest-only plans remain unverified. The template freezes approval, network, tools, CLI configuration, and filesystem roots, allowing only the isolated project and the account-bound Codex arg0 bootstrap path to vary. A production contribution or release needs a frozen `evolve plan` that declares each version scope and actual manifest version, an isolated creator request with a bound maintainer regression brief, native session/turn/tool policy evidence, explicit protected-path denies, and only trusted skill-creator/Python readonly dependencies, a bound full candidate snapshot, one durable attempt per required matrix unit, and `evolve finalize`; unknown, cancelled, and timed-out attempts are never retried. A candidate pass never authorizes a different snapshot. Use `evolve attempt native-evidence-template` to identify the original host-store session cutoff SHA-256, path hash, device, and inode required for reconstruction. Codex qualification recomputes root/pre/Post prefixes and binds a hook tool through its matching CommandExecution result; outer exec IDs are a separate namespace. WorkBuddy preparation is supported but its qualification remains unverified until it has a bounded native attribution parser. `contribute` and `release` independently reconstruct this real evidence before each prepare and execute step. Keep `runtime/`, including `runtime/SELC-LICENSE`, intact. Installed managed actions record selected executions automatically; discovery never creates lifecycle evidence. Legacy record commands remain diagnostics for legacy subjects and cannot modify managed-v2 tasks. This suite works from Codex and WorkBuddy installation directories without a full SELC checkout.
